This project is on the expansion of Signal Space Separation (SSS) Methods to adaptive spatial filters (also known as beamforming) in MEG.
The backbone of this work is built on the MNE Python infrastructure, without which this work would not be possible. 

Simulations of source spaces, head models, and code solving the forward problem for these models is included, as is source simulation code.
Alongside these simulations, the preprocessing of data and analysis via conventional and SSS methods are provided here as well. 

It is hoped such code and developments in SSS can benefit future research, especially with developing MEG technologies like OPM MEG. 

Special thanks to Samu Taulu and Eric Larson for guidance and expertise on MNE Python and source localization methods.
